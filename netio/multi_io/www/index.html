HTTP 协议看浏览器的开发者工具 → Network → Headers
连接复用上面几个按钮连点几次，Network 面板里应当只有一条连接（Connection: keep-alive）

可用的接口

  • GET /hello —— 最小动态响应，证明页面是代码现算出来的
  • GET /api/time —— 当前 UTC 时间（JSON）
  • POST /api/echo —— 回显请求正文，用来验证 Content-Length 解析是否正确
  • GET /api/info —— 服务器状态：实际生效的多路复用后端、当前连接数
  • GET /api/big?size=N —— 生成 N 字节数据，用来压测大响应的发送缓冲区

浏览器地址栏直接访问 /hello 或 /api/time 也能看到结果。 想看协议细节，用 curl -v。
